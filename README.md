# 1 Day Prototypes

Small playable game prototypes, one folder per game. Each game is a single self-contained `index.html`.

- `picky-farm-v4/` — Picky Farm v.4 market: puzzle plots grow stock, stalls sell it, grandma's requests, seed-packet swaps, level unlocks, BGM in `assets/`
- `wad-da-frog-v4/` — Wad da Frog v.4: v.3 with new painted art (sprites in `assets/`, code-drawn fallback), new logo, cover/loading screen and cream-and-plum UI
- `wad-da-frog-v3/` — Wad da Frog v.3 endless: six frog species with abilities, events (row burst, red raid, egg feast), wanted-poster missions, cracks, heartbeat, text-free tutorial
- `picky-farm-v2/` — Picky Farm v.2 test plots: free placement, picky plant families, potato harvest, bonuses
- `picky-farm/` — turn soil tiles to connect water grooves, plant picky crops on matching soil
- `wad-da-frog-attack/` — flick frogs off a sinking raft; matching frogs merge
- `wad-da-frog/` — swipe frogs from a kayak into the swamp, upside-down Suika merge

`index.html` at the root is the gallery page linking to every game. To add a game: create a folder with its `index.html`, add a thumbnail to `thumbs/`, and add a card to the gallery.
